# Пути исходников сборочного сервера

Запуск workflow `rebuild` [42287280730](https://github.com/alexqzm/ardupilot-repro/actions/runs/42287280730)
(06.11.2026, коммит `fd5b9f7`): группы Copter, Plane и Rover 4.5.7 и 4.6.3 плана `study-2026-11`,
платы Pixhawk6X и CubeOrangePlus — 12 сборок. От основного прогона он отличается двумя условиями:

- дерево исходников лежит в `/mnt/volume_nyc3_01/autotest/APM/APM` — корне дерева из путей,
  встроенных в официальные образы;
- каталог сборки `/tmp/aprepro-out` вне дерева (`waf configure --out`), как у
  `Tools/scripts/build_binaries.py`, которым собираются официальные прошивки.

Остальное — как в основном прогоне: GitHub Actions, `ubuntu-24.04`, Python 3.11.18 с zlib 1.3,
тулчейн gcc-arm-none-eabi-10-2020-q4-major.

**Итог:** все 12 файлов `.apj` побитово совпали с официальными. В девяти случаях (Pixhawk6X во
всех шести группах, CubeOrangePlus в трёх группах 4.6.3) официальный образ содержит абсолютные
пути исходников lwIP — 24 и 26 строк соответственно; пересобранный образ теперь содержит те же
строки. CubeOrangePlus в группах 4.5.7 путей не содержит и совпадает в обоих прогонах — это
контроль.

**Локальная проверка до запуска** (06.11.2026, Python 3.11.15 с классическим zlib 1.3.2, Copter
4.5.7, Pixhawk6X). Дерево в том же каталоге `/mnt/volume_nyc3_01/autotest/APM/APM`, но сборка в
`build/` внутри дерева дала тот же `.apj`, что основной прогон в CI (SHA-256 `a0d177de…`): пути
исходников в образе остались относительными (`../../modules/lwip/…`). С каталогом сборки вне
дерева пути стали абсолютными, и `.apj` совпал с официальным (SHA-256 `4a4415f9…`). Значит, дело
не в каталоге дерева самом по себе, а в том, какие пути waf передаёт компилятору: относительные,
если у дерева и каталога сборки есть общий предок ниже корня, и абсолютные, если общий предок —
только `/` (`waflib/Node.py`, `path_from`).
